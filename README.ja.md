## 概要
本リポジトリは、私のデジタルフォレンジック、インシデントレスポンス（DFIR）、およびサイバーセキュリティに関するプロジェクトをまとめたアーカイブです。エンドポイント解析、コンテナセキュリティ、ネットワークトラフィック解析、そしてセキュアな環境における人工知能（AI）の戦略的活用といった、実践的な取り組みを示しています。

## プロジェクト一覧

* [**01: エンドポイントフォレンジック**](./01-Endpoint-Forensics/README.md)
    * *概要:* リバースシェル侵入に対する Windows のメモリ（RAM）・レジストリの事後解析（永続化、アンチフォレンジックによるタイムスタンプ改ざん、BitLocker）と、Linux における偽装ファイルの検出およびファイルカービング。

* [**02: コンテナセキュリティ**](./02-Container-Security/README.md)
    * *概要:* コンテナ化された Spring/Tomcat アプリに存在する既知の重大な脆弱性（Spring4Shell）の検証と実証（エクスプロイト）。修正案は概念的（未検証）。

* [**03: ネットワークフォレンジック**](./03-Network-Forensics/README.md)
    * *概要:* インシデント対応のトリアージを目的とした、SIEM ログ相関分析（Splunk）とネットワーク偵察ツール（Nmap/NSE）の活用。パケットレベル（PCAP）解析や独自 IDS ルールの開発は含みません。

* [**04: クラウドインフラ**](./04-Cloud-Infrastructure/README.md)
    * *概要:* CloudFormation / Infrastructure Composer を用いた AWS 上の VPC・サブネットのプロビジョニング。ネットワーク層のみで、ルーティング・セキュリティグループ・コンピューティングリソースは構築していません。

* [**05: サイバーセキュリティにおける AI**](./05-AI-Cybersecurity-NIST/README.md)
    * *概要:* NIST AI RMF 1.0 フレームワークに沿って整理した、サイバーセキュリティにおける AI 活用の戦略的分析（文献・フレームワークに基づく分析文書であり、実機演習ではありません）。

* [**06: 企業内部不正（インサイダー脅威）フォレンジック**](./06-Enterprise-Insider-Threat-Forensics/README.md)
    * *概要:* 内部不正によるデータ持ち出し事案のデジタルフォレンジック調査。証拠保全の連鎖（chain of custody）および証拠管理記録（evidence control log）の文書化を含みます。

---
*注記: 6 つのプロジェクトはいずれも、大学院の DFIR 講義の演習課題であり、講師から提供された、または架空のシナリオを対象としています。実際のインシデントではありません。一部のスクリーンショットには、元教材に含まれていた演習環境の実際の情報（例: 受講者アカウントの識別子）が、秘匿処理されずにそのまま残っている箇所があります。*
